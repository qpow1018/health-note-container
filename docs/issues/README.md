# 실사용 이슈

웹·앱을 사용하며 발견한 문제의 현상, 기존 구현, 원인 조사, 해결 결정과 검증 근거를 기록한다. 현재 구조는 각 프로젝트의 아키텍처 문서에서 관리한다.

관련 기록이 있으면 이어서 갱신하고, 새 이슈는 `NNN-short-slug.md`로 추가한다. '조사하자'와 '처리하자'는 모두 조사와 해결안 제시까지이며, 제품 코드 수정은 후속 실행 요청에 따라 진행한다.

상태는 조사 중·해결안 논의·수정 중·검증 대기·해결·보류를 사용한다. 실제 현상에 대한 검증이 남으면 해결로 표시하지 않는다. 기록 방법은 [이슈 스킬](../../.agents/skills/investigating-health-note-issues/SKILL.md)을 따른다.

## 목록

아직 등록된 이슈가 없다. 등록 시 번호·제목과 문서 링크·관련 웹/앱·상태를 이 목록에 추가한다.
